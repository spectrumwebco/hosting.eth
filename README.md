# hosting.eth

A cloud-native, globally distributed domain registration platform built on web3. The goal is to build the first Panel Platform worth its weight, superior to traditional solutions like hPanel from Hostinger and cPanel.

## Project Vision

hosting.eth is revolutionizing domain registration by creating a comprehensive Panel Platform that integrates the entire elest.io library of solutions. Unlike traditional domain registrars that only offer basic website builders, hosting.eth provides custom paneling for open-source projects with a focus on security and accessibility.

### Key Features

- **Web3-Based Domain Registration**: Register and manage both traditional and blockchain domains (.eth) through a unified interface
- **Comprehensive Panel Platform**: Access and manage all your services through a single, secure interface
- **Entire elest.io Library Integration**: Support for a wide range of open-source solutions
- **Enhanced Security**: Keep services tightly coupled to domains without requiring public access
- **Cloud-Native Architecture**: Built on distributed systems principles with Kubestack and Dapr

### The Problem We Solve

Traditional domain registrars have missed the opportunity to provide real value through integrated service platforms. Most only offer basic website builders and a few hosting options, completely missing the real opportunity that only domain registrars can provide.

hosting.eth solves an underlying problem by making it easier to leverage cost-friendly alternatives to industry standards while solving cybersecurity issues. By keeping services tightly coupled to domains without requiring public access, we ensure that residual cyberthreats are not exposed.

## Technology Stack

### Frontend
- **Framework**: Quasar Framework (Vue3/TypeScript)
- **UI Libraries**: PrimeVue, Tailwind CSS
- **State Management**: TanStack Query, TanStack Store
- **Routing**: TanStack Router
- **Forms**: TanStack Form
- **Tables**: TanStack Table
- **Package Manager**: Bun
- **Web3**: Ethereum blockchain integration

### Backend
- **Language**: PHP
- **Framework**: Spiral Framework
- **ORM**: Cycle ORM
- **Server**: Swoole
- **Authentication**: Email-based 2FA

### Infrastructure
- **Container Orchestration**: Kubernetes
- **Distributed Runtime**: Dapr
- **GitOps**: Kubestack
- **CI/CD**: 8-part system with Nx build system as the foundation
- **Secret Management**: Hashicorp Vault
- **Blockchain**: Ethereum, ENS
